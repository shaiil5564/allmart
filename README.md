# AllMRT (Flipkart-like UI)

A responsive, static Flipkart-like storefront. No backend required. Open `index.html` directly in your browser.

## Features
- Header with brand, search bar, login button, more menu, and cart
- Horizontal categories row
- Banner carousel
- Product sections: Top Deals, Mobiles, Electronics
- Basic cart with localStorage, drawer UI, and total
- Responsive layout with CSS Grid and Flexbox

## Getting Started
1. Open the folder `c:/Users/de/Desktop/allmrt.com/`.
2. Double-click `index.html` to preview in your browser.

Optionally use a static server to avoid CORS issues with some features:
- VS Code Live Server, or
- Node: `npx serve .`
